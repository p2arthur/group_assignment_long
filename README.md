# Destination Selector Coursework

A small multipage HTML, CSS, and JavaScript coursework exercise centered on a destination-selection screen.

The repository includes a main page, two additional page files, shared styling, and a browser script. It preserves the group assignment's implementation stage.

## Start reading

- [`index.html`](index.html)

## View locally

Serve the repository directory with a local static server, for example:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Open [index.html](http://127.0.0.1:8000/index.html). Any CDN libraries, hosted APIs, or map providers referenced by the page still require network access.
